# Changelog

All notable changes to Skill Sync are documented here. The project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Native SwiftUI menu-bar app and manager window for macOS 14+.
- Global and project scanning across `.agents`, `.claude`, and legacy `.codex`
  skill locations.
- Previewed reconciliation with fingerprints, recoverable backups, relative
  symlinks, conflict skipping, and in-session undo.
- skills.sh search, pinned CLI installation, and global/project skill updates.
- Codex and Claude Code MCP listing, installation, removal, and official MCP
  Registry search.
- Plain-text MCP credential entry with masking, redaction, and tracked-file
  warnings.
- Sparkle 2 update checks backed by the repository appcast.
- Swift Format, SwiftLint, Swift Testing, GitHub Actions CI, universal build
  verification, and prepared signed/notarized release automation.
